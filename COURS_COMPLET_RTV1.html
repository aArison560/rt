Principe 1 — Espace vectoriel ℝ³ (8 axiomes)

Un vecteur \(\mathbf{v}=(x,y,z)\) n'est pas un point : c'est un déplacement. L'ensemble \(\mathbb{R}^3\) muni de addition et multiplication scalaire vérifie :

Addition : \(\mathbf{a}+\mathbf{b}=(a_x+b_x,a_y+b_y,a_z+b_z)\) — commutative, associative, neutre \(\mathbf{0}\), inverse \(-\mathbf{v}\)
Scalaire : \(k\mathbf{a}=(k a_x,k a_y,k a_z)\) — distributif \(k(\mathbf{a}+\mathbf{b})=k\mathbf{a}+k\mathbf{b}\), \((k+l)\mathbf{a}=k\mathbf{a}+l\mathbf{a}\)
Code : `operator+`/`operator*` `Vec3.hpp:11` — ex: `light.pos - hit.point` `Renderer.cpp:18` est bien un vecteur.

Principe 2 — Combinaison linéaire, base, dimension

Tout \(\mathbf{v}= x\mathbf{e}_1+y\mathbf{e}_2+z\mathbf{e}_3\) avec \(\mathbf{e}_1=(1,0,0)\) etc. Une base est une famille libre (aucun vecteur combinaison des autres) et génératrice (tout vecteur s'écrit dessus). \(\dim\mathbb{R}^3=3\).

Coordonnées : dans base \(\{ \mathbf{u},\mathbf{w},\mathbf{v}\}\) locale : \(\mathbf{X}= x\mathbf{u}+y\mathbf{w}+z\mathbf{v}\) avec \(x=\mathbf{X}\cdot\mathbf{u}\) etc.

Principe 1 — Base, famille libre, dimension

Dans \(\mathbb{R}^3\), une base est une famille libre (aucun vecteur n'est combinaison des autres) et génératrice (tout vecteur s'écrit comme combinaison linéaire). Alors tout \(\mathbf{X}=x\mathbf{b}_1+y\mathbf{b}_2+z\mathbf{b}_3\) de façon unique.

Théorie : Lemme de Steinitz / Théorème de la dimension — toutes les bases de \(\mathbb{R}^3\) ont 3 éléments → \(\dim\mathbb{R}^3=3\).
Ex canonique : \(\mathbf{e}_1=(1,0,0),\mathbf{e}_2=(0,1,0),\mathbf{e}_3=(0,0,1)\). RTv1 locale : \(\{\mathbf{u},\mathbf{w},\mathbf{v}\}\) avec \(\mathbf{w}=\hat{dir}=Y\), \(\mathbf{u}=X\), \(\mathbf{v}=Z\).

Principe 2 — Base orthonormée (orthogonale + normée)

Définition : \(\{\mathbf{u},\mathbf{w},\mathbf{v}\}\) orthonormée ⇔ \(\|\mathbf{u}\|=\|\mathbf{w}\|=\|\mathbf{v}\|=1\) et \(\mathbf{u}\cdot\mathbf{w}=\mathbf{w}\cdot\mathbf{v}=\mathbf{u}\cdot\mathbf{v}=0\)
Théorie : Procédé de Gram-Schmidt — orthogonaliser puis normaliser. Conséquence : coordonnées immédiates par produit scalaire (pas d'inverse de matrice) : \(x=\mathbf{X}\cdot\mathbf{u}\) etc.

Principe 1 — Repère de Descartes & droite paramétrée (Ray)

Descartes (1637 La Géométrie) : tout point \(P\) devient \((x,y,z)\in\mathbb{R}^3\). Une droite est l'ensemble \(\{\mathbf{O}+t\mathbf{D}\mid t\in\mathbb{R}\}\) où \(\mathbf{O}\) est l'origine du rayon et \(\mathbf{D}\) son vecteur directeur unitaire \(\|\mathbf{D}\|=1\).

Équation paramétrique (forme vectorielle) : \(\boxed{\mathbf{P}(t)=\mathbf{O}+t\mathbf{D},\; t\ge10^{-4}}\)
Forme cartésienne : \(\frac{x-O_x}{D_x}=\frac{y-O_y}{D_y}=\frac{z-O_z}{D_z}=t\) si \(D_i\neq0\)
RTv1 : caméra `Ray{cam.pos, dir}` `Renderer.cpp:68` et ombre `Ray{hit+N·1e-4, lightDir}` `Renderer.cpp:26` — le \(10^{-4}\) évite l'auto-intersection (acne).

Principe 2 — Plan cartésien (équation normale)

Un plan est défini par un point \(\mathbf{P}_0\) et un vecteur normal unitaire \(\mathbf{N}\) (\(\|\mathbf{N}\|=1\)).

Forme normale (Hesse 1861) : \(\boxed{\mathbf{N}\cdot(\mathbf{P}-\mathbf{P}_0)=0}\) ⇔ \(\mathbf{N}\cdot\mathbf{P}=d\) avec \(d=\mathbf{N}\cdot\mathbf{P}_0\)
Forme générale : \(Ax+By+Cz+D=0\) avec \((A,B,C)=\mathbf{N}\), \(D=-\mathbf{N}\cdot\mathbf{P}_0\) — *Théorème : tout plan est de cette forme et réciproquement si \((A,B,C)\neq0\)*
Distance signée : \(dist(\mathbf{Q},\text{plan})=\mathbf{N}\cdot(\mathbf{Q}-\mathbf{P}_0)\) (positif côté \(\mathbf{N}\))

Principe 3 — Sphère (équation quadrique centrée)

Définition euclidienne : \(\boxed{\|\mathbf{P}-\mathbf{C}\|^2=R^2}\) ⇔ \((x-C_x)^2+(y-C_y)^2+(z-C_z)^2=R^2\)
Forme développée (quadrique) : \(x^2+y^2+z^2-2C_x x-2C_y y-2C_z z+( \|\mathbf{C}\|^2-R^2)=0\) — centre \(\mathbf{C}\), rayon \(R\)
Théorie : Théorème de Pythagore 3D — la sphère est le lieu des points à distance \(R\) de \(\mathbf{C}\) ; normale en \(\mathbf{P}\) : \(\mathbf{N}= (\mathbf{P}-\mathbf{C})/R\) `Object.cpp:18`

Principe 4 — Intersection rayon → plan / sphère (cœur RTv1)

Ray–Plan `Object.cpp:23` : injecte \(\mathbf{P}(t)\) dans \(\mathbf{N}\cdot(\mathbf{P}-\mathbf{P}_0)=0\) → \(\boxed{t=\frac{(\mathbf{P}_0-\mathbf{O})\cdot\mathbf{N}}{\mathbf{N}\cdot\mathbf{D}}}\) si \(|\mathbf{N}\cdot\mathbf{D}|>10^{-6}\) (sinon //), \(t\ge10^{-4}\)

Principe 1 — Définition : forme bilinéaire symétrique → quadratique

Soit \(Q\) symétrique \(3\times3\). La forme bilinéaire \(B(\mathbf{X},\mathbf{Y})=\mathbf{X}^\top Q\mathbf{Y}\) est symétrique \(B(\mathbf{X},\mathbf{Y})=B(\mathbf{Y},\mathbf{X})\). La forme quadratique associée est sa diagonale \(q(\mathbf{X})=B(\mathbf{X},\mathbf{X})\).

\(\boxed{q(\mathbf{X})=\mathbf{X}^\top Q\mathbf{X}= Ax^2+By^2+Cz^2+Dxy+Exz+Fyz}\) avec
\(Q=\begin{pmatrix}A & D/2 & E/2\\ D/2 & B & F/2\\ E/2 & F/2 & C\end{pmatrix}\), \(\mathbf{X}=(x,y,z)^\top\) — *Théorème : toute forme quadratique s'écrit ainsi avec un unique \(Q\) symétrique*
Complète (affine) : \(F(\mathbf{X})=q(\mathbf{X})+\mathbf{L}\cdot\mathbf{X}+J\) avec \(\mathbf{L}=(G,H,I)\) — exactement \(A\ldots J\) `Quadric.hpp:25`

Principe 2 — Forme polaire & identité de polarisation

Forme polaire : \(B(\mathbf{X},\mathbf{Y})=\tfrac12\big(q(\mathbf{X}+\mathbf{Y})-q(\mathbf{X})-q(\mathbf{Y})\big)\) — Identité de polarisation
En base canonique : \(B(\mathbf{e}_i,\mathbf{e}_j)=Q_{ij}\) — donc \(D=2B(\mathbf{e}_1,\mathbf{e}_2)\), etc.
RTv1 : les termes croisés \(Dxy, Exz, Fyz\) viennent exactement de \(B\) non-diagonale. Si \(D=E=F=0\), \(Q\) est diagonale → quadrique à axes alignés.

Principe 3 — Théorème spectral (diagonalisation orthogonale)

Théorème spectral (Cauchy 1829, cas réel) : Pour tout \(Q\) réel symétrique, il existe \(P\in O(3)\) orthogonale et \(\lambda_i\in\mathbb{R}\) tels que
\(\boxed{P^\top Q P = \mathrm{diag}(\lambda_1,\lambda_2,\lambda_3)}\) avec \(P^\top=P^{-1}\), \(P=[\mathbf{e}'_1\;\mathbf{e}'_2\;\mathbf{e}'_3]\) base orthonormée de vecteurs propres.
Alors dans base propre : \(q(\mathbf{X}')=\lambda_1{x'}^2+\lambda_2{y'}^2+\lambda_3{z'}^2\) — plus de termes croisés !

Principe 4 — Rang, signature, loi d'inertie de Sylvester

Définitions : \(\mathrm{rang}(q)=\#\{\lambda_i\neq0\}\), \(n_+=\#\{\lambda_i>0\}\), \(n_-=\#\{\lambda_i<0\}\), \(n_0=\#\{\lambda_i=0\}\)
Loi d'inertie de Sylvester (1852) : \(\boxed{(n_+,n_-,n_0)\text{ invariante par }P^\top QP}\) (changement de base quelconque, pas seulement orthogonale) — c'est un invariant projectif de la quadrique.
Rang + signature → type : voir tableau Fig 4.4 — même \(q\) peut donner ellipsoïde, hyperboloïde, paraboloïde, cylindre ou cône selon \(n_0\) et le terme linéaire \(\mathbf{L}\).

Principe 1 — Définition : FPS = 1 / \(T_{frame}\)

\(\boxed{\text{FPS}=\frac{1}{T_{frame}}}\) avec \(T_{frame}\) en secondes ; \(\boxed{T_{frame}[ms]=\frac{1000}{\text{FPS}}}\)
Repères : 1 fps → 1000 ms, 24 fps → 41.7 ms (cinéma), 30 fps → 33.3 ms, 60 fps → 16.6 ms, 144 fps → 6.94 ms, 240 fps → 4.17 ms.
RTv1 actuel : `quadriques.rt` 1080×720 → 188 ms → \(1000/188≈5.3\) fps (`/tmp/bench`); 540×360 → 47 ms → 21.3 fps.

Principe 2 — Perception humaine : persistance & flicker

Loi de Ferry-Porter : fréquence de fusion \(f_{fusion}\approx 50-60\) Hz — au-delà, l'œil ne voit plus le scintillement.
Seuils : 10-12 fps → saccadé (Muybridge 1878), 24 fps → cinéma (trompe le cerveau, motion blur aide), 30 fps → TV, 60 fps → fluide interactif (souris), 90-144 fps → VR/compétitif.
RTv1 : 5 fps → diaporama ; 21 fps → jouable mais saccadé ; 60 fps → cible Blender-like.

Principe 3 — Mesurer : bench, ms vs FPS, 1% low

Mesure RTv1 `bench` : `chrono::high_resolution_clock` avant/après `Renderer::render` → \(T_{frame}\) en ms → FPS.\(10\) frames moyennées.
Piège : moyenne FPS ≠ 1/(moyenne ms) si variance. Mieux : frame time en ms et 1% low (pire 1%). Ex: 60 fps moyen mais 1% low 20 fps → saccade.
V-Sync : limite à 60 Hz écran → si \(T<16.6\) ms → attente, si \(T>16.6\) → drop à 30 fps (moitié).

Principe 4 — Ce qui coûte : \(w\cdot h\cdot N_{obj}\) (exemple RTv1)

\(\boxed{T \propto w\cdot h\cdot N_{obj}}\) — cf. Ch.10. Exemple chiffré : 1080×720=777k, ×6=4.6M intersect, ×188 ms → 40 µs / intersect.
Si on double : 2× résolution → 4× pixels → 752 ms (1.3 fps) ; 2× objets → 376 ms (2.6 fps).
Donc : pour gagner 2× FPS, diviser par 2 la résolution ou par 2 les objets (BVH) ou par 2 le coût intersect (cache).

Principe 5 — Budget 16.6 ms : comment tenir 60 fps

Budget 60 fps = 16.6 ms à répartir :
\(\boxed{16.6 = T_{ray}+T_{shade}+T_{present}}\) ex: 8 ms génération rayons + 6 ms ombrage `Renderer.cpp:17` + 2 ms `SDL_RenderPresent` / vsync.
Stratégie Blender : interaction → 540×360 (47 ms → encore trop) → ajoute BVH (÷6) → 7.8 ms → OK + marge pour UI.
Règle : garder \(T_{frame}<16.6\) sinon drop à 30 fps (vsync) ou tearing (sans vsync).
